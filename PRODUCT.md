# PRODUCT.md

## Register
brand

## Surface
Personal tech blog — long-form technical articles about AI-assisted development, complex systems engineering, and testing architecture.

## Users
Software engineers and tech leads reading in-depth technical articles. Context: desktop or mobile, focused reading, reference material.

## Purpose
Share deep technical insights and architectural thinking. The design should feel authoritative, clean, and focused on readability.

## Brand Personality
Authoritative, precise, thoughtful

## Anti-references
- Generic SaaS landing pages with hero metrics
- Overly decorative portfolios with excessive animations
- Warm/cream/beige "cozy blog" aesthetics
- Gradient text, glassmorphism, side-stripe borders

## Design Principles
- Typography-first: readability is paramount
- Restrained color: one accent, neutral base
- Consistent template: all article pages share identical UI structure
- Dark mode: first-class support, not an afterthought
- Motion: purposeful, not decorative

## Accessibility
- WCAG AA contrast minimum (4.5:1 body text, 3:1 large text)
- Reduced motion support
- Semantic HTML structure

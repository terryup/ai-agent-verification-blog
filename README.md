# AI Agent Verification Blog

这是发布到 GitHub Pages 的脱敏静态博客产物。

## 发布

1. 在 GitHub 创建公开仓库，例如 `ai-agent-verification-blog`。
2. 将本目录全部文件提交到仓库根目录。
3. 在 `Settings -> Pages` 中选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/ (root)`。
5. 等待 Pages 部署完成。

发布地址通常是：

```text
https://<your-github-username>.github.io/ai-agent-verification-blog/
```

## 脱敏说明

- 已移除原始 workflow 链接。
- 已将具体项目/类/协议名替换为抽象名称。
- 仅包含页面实际引用的图片和 SVG 资源。
